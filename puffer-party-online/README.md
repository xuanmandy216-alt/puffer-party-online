# 河豚炸弹派对 · V2.4 联机规则实现（开发预览）

Node.js + Express + Socket.IO。2–10 名参赛玩家；房主设置 1/2/3/5 颗生命、五类题库；全部准备后开局。每题 3 秒准备、每次答题 15 秒；答错和重复只提示，超时才扣生命。支持服务器判题、答对传递、淘汰观战、提前结束、排行榜、同浏览器身份重连、加入后观战。

## 运行

```bash
npm install
npm start
```

打开 http://localhost:3000。Render Web Service：Build `npm install`，Start `npm start`。

## 题库进度（重要）

`data/questions.json` 目前仅有 **6 道开发用样本题**，不是已完成的 250 道正式题库。每题在服务启动时校验至少 30 个不同标准答案。标准答案以逗号分隔，别名写在 `aliases` 对象中。尚未完成全量事实核验、简繁转换和所有游戏角色的官方别名录入；样本题也应继续人工复核。未经审核的候选题不应直接用于正式上线。

## 注意

- 房间和身份凭据暂存服务器内存；重启或所有人断开会销毁房间。
- 当前题目和答案由服务器控制；客户端不收到答案清单。
- 断线不会停止倒计时；同一浏览器重连可恢复身份，主动退出则退赛。
- 暂未部署到 GitHub/Render。请先在本地或测试环境多人联机验收。
