# 🐡 河豚炸弹派对 · 中文多人在线版

每位玩家用自己的手机或电脑打开同一个公网网址，输入昵称，创建或加入 6 位房间码，实时轮流回答中文问题。

## 本地运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm start
```

浏览器打开 http://localhost:3000 。本地测试多玩家时，可以开多个浏览器标签页。**朋友在异地时，必须先部署到公网；localhost 只能在运行服务的电脑上访问。**

## 部署到 Render（示例）

1. 将本项目的所有文件上传到一个 GitHub 仓库（确保 `server.js`、`package.json` 和 `public/index.html` 都在）。
2. 在 Render 创建 **Web Service**，连接该仓库，运行环境选 **Node**。
3. Build Command 填 `npm install`，Start Command 填 `npm start`。
4. 部署成功后，复制 Render 提供的 `https://...onrender.com` 网址给朋友。
5. 一人创建房间，其他人打开链接输入房间码加入。

注意：免费服务可能休眠或有限制；平台套餐和设置可能变化。此版本的房间存于服务器内存，服务重启会清空；请保持单实例运行，不要启用多实例负载均衡。

## 规则

- 2–10 人；房主选择题库、生命值及随机爆炸时间范围。
- 系统随机指定当前回答者，所有人实时看到题目、玩家生命值和答案记录。
- 当前玩家输入答案后，河豚自动传给下一名存活玩家。
- 同一轮禁止重复**完全相同或仅标点/空格不同**的答案。
- 爆炸时持有河豚的玩家失去一颗心；最后存活者获胜。
- 中文开放题没有语义判题功能：玩家自行判断答案是否符合题目。
- 玩家退出/断线会离开房间；刷新页面需要重新加入，正在进行的房间暂不支持中途加入。

## 项目结构

- `server.js` — Express + Socket.IO 服务端，管理房间、回合、倒计时和胜负。
- `public/index.html` — 响应式中文游戏界面。
- `package.json` — 依赖与启动命令。

此项目为原创示例，不包含第三方网站的源代码、图片或商标素材。
